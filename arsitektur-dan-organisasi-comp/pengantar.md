# Arsitektur & Organisasi Komputer

Catatan kuliah — 9 September 2026

## Computer Architecture vs Computer Organization

| | Computer Architecture (Comp. Arch.) | Computer Organization (Comp. Org.) |
|---|---|---|
| Fokus | Desain struktur sistem dalam komputer | Implementasi teknis — bagaimana komponen bekerja |
| Komponen Utama | Set instruksi (ISA), aritmatika yang digunakan, teknik pengalamatan, mekanisme Input/Output (I/O) | Sirkuit, memori, antarmuka |

## Sejarah Komputer dan Evolusi Teknologi

### Awal Perkembangan Komputer

**a. Alat Hitung Tradisional**
Abacus/sempoa — dipakai di Tiongkok dan Romawi. Tanpa listrik, ringan, mudah, dan manual.

**b. Mesin Mekanik (Abad ke-17)**
- **Pascaline** — terbatas pada penjumlahan dan pengurangan
- **Stepped Reckoner** — mulai bisa perkalian dan pembagian, menggunakan silinder bergerigi

**c. Charles Babbage dan Konsep Komputer Modern**
Generasi awal konsep tabel matematik otomatis dengan sistem mekanik presisi:
- **Difference Engine** — untuk tabel matematika presisi
- **Analytical Engine** (pakai punch card) — hampir menyamai komputer modern karena sudah ada komponen pemrosesan, penyimpanan, dan instruksi

**d. First Generation (1940–1956)**
Tabung vakum sebagai komponen utama. Contoh: ENIAC — ukuran super besar.

**e. Second Generation (1956–1963)**
Transistor menggantikan tabung vakum. Bahasa pemrograman tingkat tinggi mulai berkembang — Fortran dan Cobol.

**f. Third Generation (1964–1971)**
Integrated Circuit (IC) — lebih efisien dan mulai mendukung sistem operasi.

**g. Fourth Generation (1971–sekarang)**
Microprocessor.

**h. Fifth Generation**
AI, Machine Learning, IoT, Quantum Computer.

### Ringkasan Evolusi per Kategori

| Kategori | Evolusi |
|---|---|
| **Hardware** | Tabung Vakum → Transistor → IC → Microprocessor → GPU, NPU, dst. |
| **Software** | Bahasa mesin → Assembly → C → OS → Cloud-based |
| **Storage** | Punch card → Tape magnet → HDD → SSD → Cloud |
| **Jaringan** | ARPANET → Internet → Mobile network → IoT |
